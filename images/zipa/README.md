# ZIPA Mobile App UI Design System & Screen Assets

This folder contains the complete, production-grade UI design mockups for **ZIPA** — a Nigeria-focused digital wallet, multi-currency transfer, crypto asset, utilities, and small business invoicing app designed for iPhone 16 Pro (393×852px).

---

## 🎨 Color Tokens & Visual System

- **Background (Canvas):** `#F8FAF8` (Warm Off-white)
- **Surface:** `#FFFFFF` (Pure White)
- **Primary:** `#0B6B45` (Deep Forest Green)
- **Secondary:** `#16875B` (Emerald)
- **Accent:** `#DFF6E8` (Soft Mint)
- **Ink / Text:** `#17211C` (Near-black)
- **Muted Text:** `#69756E` (Muted Gray)
- **Borders:** `#E4EBE6` (Subtle Gray-Green)
- **Error / Warning:** `#C83F45` / `#E08A00`

## 📱 Screen Inventory

### A. First Use & Account Setup
- `01_landing_welcome.png` — Landing / Welcome screen with connected money paths motif and primary action.
- `02_signup.png` — Sign up screen with Nigeria (+234) country selector and privacy consent.
- `03_login.png` — Returning user login with secure password and Face ID biometric option.
- `04_handle_setup.png` — Custom `@adaeze` ZIPA handle claim with live availability badge.
- `05_kyc_verification.png` — Tier 2 identity verification with NIN, Passport, Driver's Licence options.

### B. Home, Wallet & Crypto
- `06_dashboard_home.png` — Authenticated Home Dashboard with balance card, quick actions, and recent ledger.
- `07_wallet.png` — Cash Wallet balance overview separated from crypto holdings.
- `08_crypto_portfolio.png` — Crypto asset valuation, 7-day sparkline, and token cards (USDT, USDC, BTC, ETH).
- `09_buy_crypto.png` — NGN to USDT purchase calculator with zero-fee badge and 45s quote timer.
- `10_sell_crypto.png` — Sell crypto to NGN with MAX selector, indicative rate, and payout estimate.

### C. Payments & Authorization Pipeline
- `11_send_recipient.png` — Recipient search by `@handle`, recent contacts, and recipient check.
- `12_send_amount.png` — Amount entry keypad (`₦25,000.00`) with note and fee preview.
- `13_crypto_send.png` — USDT TRC20 send form with address QR scan and irreversibility warning.
- `14_receive.png` — Receive screen with `@handle` QR code and crypto address tabs.
- `15_transaction_review.png` — Pre-authorization transaction review card before biometric prompt.
- `16_passcode_authorization.png` — Masked 4-digit PIN keypad and Face ID prompt modal.
- `17_transaction_result.png` — Completed transaction receipt with Reference ID and Share CTAs.

### D. Utility & Household Bills
- `18_pay_hub.png` — 2x2 Bills directory (Airtime, Data, Electricity, Cable TV).
- `19_airtime.png` — Airtime top-up form for MTN, Airtel, Glo, 9mobile.
- `20_data.png` — Network data plan selector with validity and pricing tiers.
- `21_electricity.png` — Electricity payment with Disco selector (IKEDC/EKEDC) and meter name verification.
- `22_cable_tv.png` — Cable TV package renewal with Smartcard IUC lookup.

### E. Activity Ledger & Receipts
- `23_activity.png` — Chronological transaction ledger with category filters and signed amounts.
- `24_transaction_detail.png` — Full receipt breakdown with Support routing.

### F. Small Business & Invoicing
- `25_invoice_list.png` — Invoice dashboard with Draft, Outstanding, and Paid metrics.
- `26_invoice_create.png` — Invoice creation form with line items, quantities, and subtotal.
- `27_public_invoice.png` — Responsive customer web invoice view with direct payment CTA.

### G. People, Profile & Security
- `28_contacts.png` — Saved contacts directory and friend invite actions.
- `29_profile.png` — Account overview, Level 2 NIN verification badge, and settings navigation.
- `30_security.png` — Security center with passcode management, 2FA, and trusted sessions.
