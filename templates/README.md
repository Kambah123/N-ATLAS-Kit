# Templates

Three small apps on the published SDKs (`n-atlas` on npm, and the same gateway the Python `natlas` package calls). None of them put `NATLAS_API_KEY` in the browser.

| App           | Path                               | What it does                                  |
| ------------- | ---------------------------------- | --------------------------------------------- |
| Hausa support | [`hausa-support`](./hausa-support) | Next.js shop assistant that replies in Hausa. |
| Farmer advice | [`farmer-advice`](./farmer-advice) | Next.js advice in Hausa, Yorùbá, or Igbo.     |
| WhatsApp bot  | [`whatsapp-bot`](./whatsapp-bot)   | Node webhook for the WhatsApp Cloud API.      |

Each README lists the env vars. The Next.js apps have a Deploy with Vercel button.
